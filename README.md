# Let's Encrypt (lets-encrypt)
Let's Encrypt is a free, automated, and open certificate authority run by the Internet Security Research Group affiliated with the Linux Foundation. It provides TLS certificates to secure the web, having issued billions of certificates to enable HTTPS for websites worldwide via the ACME protocol.

## APIs

### Let's Encrypt ACME API
The ACME (Automatic Certificate Management Environment) protocol API, defined by RFC 8555, used by Let's Encrypt to automate the issuance, renewal, and revocation of free TLS/SSL certificates that secure websites with HTTPS.

**Human URL:** [https://letsencrypt.org/docs/](https://letsencrypt.org/docs/)

**Base URL:** https://acme-v02.api.letsencrypt.org

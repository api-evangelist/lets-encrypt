# Let's Encrypt (lets-encrypt)
Let's Encrypt is a free, automated, and open certificate authority run by the Internet Security Research Group affiliated with the Linux Foundation. It provides TLS certificates to secure the web, having issued billions of certificates to enable HTTPS for websites worldwide.

### Let's Encrypt API
API for Let's Encrypt certificate authority, providing automated issuance and management of free TLS/SSL certificates using the ACME protocol to secure websites with HTTPS.
